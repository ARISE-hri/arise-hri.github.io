# RoboSocial
Project page for ARISE: From Social Reasoning to Embodied Interaction

Website: https://robosocial.github.io/

The presentation video appears below the publication header. Birthday Gift, Whose Bag,
and Clean Up Desk videos appear at the end of the page. Videos load on demand and
retain native playback controls. Set `video` in `links.js` to a public YouTube URL
when available; until then, the header's Video button opens the embedded presentation.
